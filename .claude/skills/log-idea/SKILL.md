# Log idea

Append one entry to `docs/ideas.md` (create it with a `# Ideas` heading if missing).

Entry format, newest at the bottom:

```
- YYYY-MM-DD: <idea in one or two sentences, in the user's words>
```

Rules:
- Use today's date.
- Keep the user's wording; tidy only typos. Do not expand, critique, or plan.
- If the idea is clearly several ideas, add one entry each.
- Do not commit. Reply with the single line you added.
